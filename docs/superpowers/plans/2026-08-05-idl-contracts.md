# IDL v1 and the Contract Toolchain — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `idl/*.idl` the single source for the twelve syscall signatures and the four on-disk record layouts, so a disagreement between the kernel and a component is a compile error instead of silent argument corruption.

**Architecture:** A C tool (`tools/idlc`) parses `.idl` files into an AST and drives four independent emitters: a Zig guest SDK, a C guest SDK, the WAMR `NativeSymbol` table the kernel includes, and a header of `_Static_assert`s that pins the hand-written on-disk structs. Generated files are committed; `make idl-check` fails if they drift from their source. The `_impl` bodies in `kernel/wasm/syscalls.c` are never generated.

**Tech Stack:** C11 (clang, ASan/UBSan for hosted tests), Zig (components and trust-boundary validators), GNU make, WAMR classic interpreter.

## Global Constraints

- **No comments in code.** Standing project preference. Explanations go in commit messages and the devlog, never in source. Generated files are the sole exception: each carries a one-line `GENERATED by tools/idlc — do not edit` banner.
- **Do not refactor working code outside the stated scope.** Ask first.
- **`make test` must pass before any task is claimed complete.** Never assert a fix without pasting the output.
- **Hosted-first (blueprint R3).** Every new logic path gets a hosted test under `HOST_CFLAGS` (`-Wall -Wextra -Werror -g -O1 -fsanitize=address,undefined`).
- **`HOST_CC := clang`**, `HOSTED_DIR := tools/hosted`, `BUILD_DIR := build`.
- Hosted tests follow the house pattern: `#include "check.h"`, a file-scope `unsigned long checks_passed;`, `CHECK(...)` per assertion, and a `main` ending with `printf("<name>: %lu checks passed\n", checks_passed);`.
- **Generated files are committed to git**, not built on demand. The kernel build must never depend on `idlc` having run.
- Branch: `slice3-idl-contracts`, already created, currently at the two design commits.

## Blocking input: the grammar is Jacob's

Per the working agreement, the IDL grammar is a permanent format and therefore Jacob's to write. **Tasks 3 onward implement against the concrete syntax below, which is a proposal for Jacob to accept or amend.**

It is included so the plan is executable rather than blocked. If Jacob changes the syntax, only Tasks 3 and 4 (lexer, parser) change; the emitters consume the AST and are unaffected.

### Proposed syntax — `idl/syscalls.idl`

```
syscall log(message: slice<u8>) -> i32;
syscall object_create(type: type-id, size: u32) -> i32;
syscall object_read(slot: cap, offset: u32, buffer: out slice<u8>) -> i32;
syscall object_write(slot: cap, offset: u32, buffer: slice<u8>) -> i32;
syscall object_size(slot: cap) -> i64;
syscall cap_drop(slot: cap) -> i32;
syscall message_send(target: cap, payload: slice<u8>, capability: cap?) -> i32;
syscall message_recv(buffer: out slice<u8>, capability_out: out i32) -> i32;
syscall timer_set(delay_ticks: u64) -> i32;
syscall time_logical() -> i64;
syscall self() -> i32;
syscall exit(code: i32);
```

### Lowering rules (D3.14)

| IDL type | WASM parameters | WAMR letters | Validator |
|---|---|---|---|
| `slice<u8>` | `u32 pointer, u32 length` | `ii` | `jani_syscall_check_span` |
| `type-id` | `i64 high, i64 low` | `II` | none (lowering only) |
| `cap` | `i32` | `i` | `jani_syscall_check_slot` |
| `cap?` | `i32` | `i` | `jani_syscall_check_optional_slot` |
| `u32`, `i32` | `i32` | `i` | none |
| `u64`, `i64` | `i64` | `I` | none |
| return `i32` / `i64` / absent | — | `i` / `I` / empty | — |

`out` is a direction modifier, not a type: it applies to `slice<u8>` and to
`i32`, and does not change lowering. `out slice<u8>` lowers exactly as
`slice<u8>`; `out i32` lowers as one `i32` and emits `?*i32` on the guest side,
where address zero already means "no output pointer". `ptr<i32>` was removed in
`fc2054a2` — it was a second spelling for the same concept.

**These rules reproduce all twelve existing signature strings exactly** — verified against `kernel/wasm/syscalls.c:424-437`. Task 6 asserts this, so a lowering bug fails a test rather than corrupting arguments.

### Proposed syntax — `idl/records.idl`

Offsets are explicit. The `.idl` documents the real layout, and the conformance emitter is a direct transcription with no layout inference.

```
record component_registry_header size 32 {
    magic:                u64 @ 0;
    format_version:       u32 @ 8;
    component_count:      u32 @ 12;
    next_sequence:        u64 @ 16;
    payload_crc32c:       u32 @ 24;
    _reserved:            u32 @ 28;
}

record component_root_record size 72 {
    magic:                u64 @ 0;
    format_version:       u32 @ 8;
    _reserved:            u32 @ 12;
    module_id:            object-ref @ 16;
    captable_id:          object-ref @ 32;
    state_id:             object-ref @ 48;
    payload_crc32c:       u32 @ 64;
    _padding:             u32 @ 68;
}

record component_captable_header size 32 {
    magic:                u64 @ 0;
    format_version:       u32 @ 8;
    slot_count:           u32 @ 12;
    next_object_sequence: u64 @ 16;
    payload_crc32c:       u32 @ 24;
    _reserved:            u32 @ 28;
}

record instance_state_header size 64 {
    magic:                u64 @ 0;
    format_version:       u32 @ 8;
    header_size:          u32 @ 12;
    logical_time:         u64 @ 16;
    timer_deadline:       u64 @ 24;
    timer_armed:          u32 @ 32;
    mailbox_used:         u32 @ 36;
    memory_size:          u64 @ 40;
    payload_crc32c:       u32 @ 48;
    _reserved:            u32 @ 52;
    _padding:             u64 @ 56;
}
```

`object-ref` is `struct object_id` — two `u64`s, 16 bytes (`kernel/obj/object_id.h:7-10`).

## Task 1: The checked-deadline validator

D3.11 makes `timer_set` take `u64`. Unlike the three object calls, it has no upper bound behind its sign check, so `logical_time + delay` can wrap and turn a distant timer into an immediate one. This task adds the guard **before** the ABI changes, so the two are separately bisectable.

**Files:**
- Modify: `kernel/wasm/syscall_args.zig` (append)
- Modify: `kernel/wasm/syscall_args.h` (append)
- Test: `tools/hosted/test_syscall_args.c` (append)

**Interfaces:**
- Consumes: nothing.
- Produces: `int jani_syscall_deadline(uint64_t logical_time, uint64_t delay_ticks, uint64_t *deadline_out);` — returns 1 and writes the deadline when `logical_time + delay_ticks` does not overflow `u64`; returns 0 and leaves `*deadline_out` untouched otherwise. Returns 0 if `deadline_out` is NULL.

```zig
export fn jani_syscall_deadline(
    logical_time: u64,
    delay_ticks: u64,
    deadline_out: [*c]u64,
) callconv(.c) c_int {
    if (deadline_out == null) {
        return 0;
    }

    const sum = @addWithOverflow(logical_time, delay_ticks);
    if (sum[1] != 0) {
        return 0;
    }

    deadline_out.* = sum[0];
    return 1;
}
```

- [ ] **Step 5: Write `lexer.c`**

```c
#include "lexer.h"

#include <string.h>

static int is_ident_start(char c) {
    return ((c >= 'a') && (c <= 'z')) || ((c >= 'A') && (c <= 'Z')) ||
           (c == '_');
}

static int is_ident_part(char c) {
    return is_ident_start(c) || ((c >= '0') && (c <= '9')) || (c == '-');
}

static int is_digit(char c) {
    return (c >= '0') && (c <= '9');
}

static struct idl_token make(struct idl_lexer *lexer, enum idl_token_kind kind,
                            const char *text, size_t length) {
    struct idl_token token;

    token.kind = kind;
    token.text = text;
    token.length = length;
    token.number = 0;
    token.line = lexer->line;
    return token;
}

void idl_lexer_init(struct idl_lexer *lexer, const char *source,
                    size_t length) {
    lexer->source = source;
    lexer->length = length;
    lexer->position = 0;
    lexer->line = 1;
}

static void skip_trivia(struct idl_lexer *lexer) {
    while (lexer->position < lexer->length) {
        char c = lexer->source[lexer->position];

        if (c == '\n') {
            lexer->line += 1;
            lexer->position += 1;
        } else if ((c == ' ') || (c == '\t') || (c == '\r')) {
            lexer->position += 1;
        } else if ((c == '/') && ((lexer->position + 1u) < lexer->length) &&
                   (lexer->source[lexer->position + 1u] == '/')) {
            while ((lexer->position < lexer->length) &&
                   (lexer->source[lexer->position] != '\n')) {
                lexer->position += 1;
            }
        } else {
            return;
        }
    }
}

struct idl_token idl_lexer_next(struct idl_lexer *lexer) {
    skip_trivia(lexer);

    if (lexer->position >= lexer->length) {
        return make(lexer, IDL_TOK_EOF, lexer->source + lexer->position, 0);
    }

    const char *start = lexer->source + lexer->position;
    char c = *start;

    if (is_ident_start(c)) {
        size_t length = 0;

        while (((lexer->position + length) < lexer->length) &&
               is_ident_part(lexer->source[lexer->position + length])) {
            length += 1;
        }
        lexer->position += length;

        if ((length == 7u) && (memcmp(start, "syscall", 7u) == 0)) {
            return make(lexer, IDL_TOK_SYSCALL, start, length);
        }
        if ((length == 6u) && (memcmp(start, "record", 6u) == 0)) {
            return make(lexer, IDL_TOK_RECORD, start, length);
        }
        if ((length == 4u) && (memcmp(start, "size", 4u) == 0)) {
            return make(lexer, IDL_TOK_SIZE, start, length);
        }
        return make(lexer, IDL_TOK_IDENT, start, length);
    }

    if (is_digit(c)) {
        size_t length = 0;
        uint64_t value = 0;
        struct idl_token token;
        int hex = 0;

        if ((c == '0') && ((lexer->position + 1u) < lexer->length) &&
            (lexer->source[lexer->position + 1u] == 'x')) {
            hex = 1;
            length = 2;
        }

        while ((lexer->position + length) < lexer->length) {
            char d = lexer->source[lexer->position + length];

            if (is_digit(d)) {
                value = (value * (hex ? 16u : 10u)) + (uint64_t)(d - '0');
            } else if (hex && (d >= 'a') && (d <= 'f')) {
                value = (value * 16u) + (uint64_t)(d - 'a') + 10u;
            } else if (hex && (d >= 'A') && (d <= 'F')) {
                value = (value * 16u) + (uint64_t)(d - 'A') + 10u;
            } else {
                break;
            }
            length += 1;
        }
        lexer->position += length;

        token = make(lexer, IDL_TOK_NUMBER, start, length);
        token.number = value;
        return token;
    }

    if ((c == '-') && ((lexer->position + 1u) < lexer->length) &&
        (lexer->source[lexer->position + 1u] == '>')) {
        lexer->position += 2;
        return make(lexer, IDL_TOK_ARROW, start, 2);
    }

    lexer->position += 1;

    switch (c) {
    case '(': return make(lexer, IDL_TOK_LPAREN, start, 1);
    case ')': return make(lexer, IDL_TOK_RPAREN, start, 1);
    case '{': return make(lexer, IDL_TOK_LBRACE, start, 1);
    case '}': return make(lexer, IDL_TOK_RBRACE, start, 1);
    case '<': return make(lexer, IDL_TOK_LANGLE, start, 1);
    case '>': return make(lexer, IDL_TOK_RANGLE, start, 1);
    case ',': return make(lexer, IDL_TOK_COMMA, start, 1);
    case ':': return make(lexer, IDL_TOK_COLON, start, 1);
    case ';': return make(lexer, IDL_TOK_SEMI, start, 1);
    case '?': return make(lexer, IDL_TOK_QUESTION, start, 1);
    case '@': return make(lexer, IDL_TOK_AT, start, 1);
    default:  return make(lexer, IDL_TOK_ERROR, start, 1);
    }
}
```
